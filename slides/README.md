  슬라이드와 그림은 자동 검사가 보지 못한다. 공유하기 전에 사람이 본다 ([CLAUDE.md](../CLAUDE.md) "자동 검사").
- 발표의 시연과 화면 그림은 개선 단계가 들어간 `main` 으로 맞춘다. 마감 때 끝나지 않은 단계는 한계로 적는다 (PRD 8절, 12절).
