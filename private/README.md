# private — 내부 자료 전용 폴더

이 폴더에 넣은 파일은 깃에 올라가지 않는다 (`.gitignore` 로 이 안내 파일만 빼고 모두 무시한다).

- 워커힐 내부 자료, 실제 고객 정보처럼 공개되면 안 되는 파일은 **이 폴더에만** 둔다.
- 이 폴더의 내용은 각자 PC 에만 있다. 팀원끼리는 저장소가 아닌 다른 경로로 주고받는다.
- 이 폴더의 자료에 있는 실제 수치, 이름, 문장을 저장소의 다른 파일에 옮겨 적지 않는다.
  규칙의 원본은 [CLAUDE.md](../CLAUDE.md) 의 "비밀값과 공개 저장소" 절이다.

올라가지 않는지 확인하는 방법:

```powershell
git check-ignore -v private/<파일 이름>
```

무시되는 파일이면 규칙이 적힌 줄이 출력되고, 아무것도 출력되지 않으면 올라갈 수 있는 파일이다.
